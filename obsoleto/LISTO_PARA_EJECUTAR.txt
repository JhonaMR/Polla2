================================================================================
                          PASOS PARA EJECUTAR
================================================================================

PASO 1: CREAR BASE DE DATOS
────────────────────────────

Opción A - pgAdmin (GUI):
  1. Abrir pgAdmin
  2. Conectar a servidor en localhost:5555
  3. Click derecho en "Databases" → "Create" → "Database"
  4. Nombre: PickEm
  5. Click "Save"

Opción B - Terminal:
  psql -U postgres -h localhost -p 5555
  CREATE DATABASE "PickEm";
  \q

PASO 2: CREAR TABLAS
────────────────────

Opción A - pgAdmin:
  1. Abrir pgAdmin
  2. Conectar a BD PickEm
  3. Click en "Query Tool"
  4. Copiar contenido de: backend/setup-db.sql
  5. Pegar y ejecutar

Opción B - Terminal:
  psql -U postgres -h localhost -p 5555 -d PickEm -f backend/setup-db.sql

PASO 3: GENERAR HASH DE CONTRASEÑA
──────────────────────────────────

  cd backend
  npm install
  node generate-hash.js

  Copiar el hash generado (comienza con $2a$10$)

PASO 4: INSERTAR DATOS INICIALES
────────────────────────────────

  1. Abrir: backend/seed-data.sql
  2. Reemplazar: $2a$10$YourHashedPasswordHere123456789012345678901234567890
     Con el hash generado en PASO 3
  3. Ejecutar en pgAdmin o terminal:
     psql -U postgres -h localhost -p 5555 -d PickEm -f backend/seed-data.sql

PASO 5: INICIAR BACKEND
──────────────────────

  cd backend
  npm install (si no lo hiciste)
  npm run dev

  Deberías ver:
  ✓ Database connected successfully
  ✓ Server running on http://localhost:3001

PASO 6: INICIAR FRONTEND
───────────────────────

  En otra terminal, en raíz del proyecto:
  npm install
  npm run dev

  Deberías ver:
  ✓ Local: http://localhost:3000

PASO 7: ACCEDER AL SISTEMA
──────────────────────────

  1. Abrir: http://localhost:3000
  2. Login con:
     Usuario: SOP
     Contraseña: Admin123!

================================================================================
                          TROUBLESHOOTING
================================================================================

Error: "connect ECONNREFUSED 127.0.0.1:5555"
  → PostgreSQL no está corriendo en puerto 5555
  → Iniciar PostgreSQL en puerto 5555

Error: "database PickEm does not exist"
  → BD no fue creada
  → Ejecutar: CREATE DATABASE "PickEm";

Error: "CORS error"
  → Frontend no puede conectar a backend
  → Verificar que backend esté en puerto 3001
  → Reiniciar ambos servidores

Error: "Invalid credentials"
  → Usuario o contraseña incorrectos
  → Verificar que SOP existe en BD
  → Verificar hash de contraseña
